# IPL Match Winning Prediction 🏏

A **Machine Learning project** that predicts the **winning probability of IPL teams** based on the current match situation such as score, overs, wickets, and target.

The model is trained on **historical IPL match data** and uses **feature engineering and feature selection techniques** to improve prediction accuracy.

# 📌 Project Overview

The goal of this project is to build a **machine learning model capable of predicting the probability of a team winning an IPL match** during the second innings.

The model analyzes match conditions like:

* Batting Team
* Bowling Team
* Match City
* Target Score
* Current Score
* Overs Completed
* Wickets Lost

Based on these inputs, the system predicts the **winning probability for both teams**.

---

# 🧠 Machine Learning Workflow

### 1️⃣ Data Collection

Historical IPL datasets were used:

* `matches.csv`
* `deliveries.csv`

---

### 2️⃣ Data Preprocessing

Steps performed:

* Data cleaning
* Handling missing values
* Encoding categorical variables
* Preparing dataset for model training

---

### 3️⃣ Feature Engineering

Created additional features to improve model performance:

* Runs Left
* Balls Left
* Wickets Remaining
* Current Run Rate (CRR)
* Required Run Rate (RRR)

---

### 4️⃣ Feature Selection

Selected the most relevant features for prediction to improve model efficiency and accuracy.

---

### 5️⃣ Model Training

A **Machine Learning classification model** was trained using **Scikit-learn**.

---

### 6️⃣ Prediction System

The trained model predicts **winning probability for both teams based on the current match state**.
